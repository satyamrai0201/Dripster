# 🧢 Dripster – A Gen Z Fashion E-Commerce Store

Dripster is a modern, fast, and aesthetic fashion e-commerce web app designed for Gen Z consumers. Built with **React.js + TypeScript**, styled using **Tailwind CSS**, and powered by **Firebase** and **Supabase**, it delivers a curated shopping experience that feels bold and lightning-fast.
 


[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)



---

## ✨ Features

- 🔐 **Google Authentication** via Firebase
- 🛍️ Dynamic **Explore**, **Wishlist**, and **Cart** pages
- 🎨 **Drip AI Fashion Chatbot** for outfit matching and color pairing
- 💡 Smooth animations with Framer Motion
- 📱 Responsive design optimized for mobile & desktop
- ⚡ Built with Vite for lightning-fast builds

---

## 🧠 Drip AI Fashion Chatbot

Our integrated **Drip AI Fashion Chatbot** helps users:

- Match outfits based on uploaded images or selected pieces
- Suggest complementary color pairings
- Recommend trendy combinations tailored to Gen Z fashion culture

---

## 🛠️ Tech Stack

- **Frontend:** React.js, TypeScript, Tailwind CSS
- **Routing:** React Router
- **Auth & Hosting:** Firebase
- **Database:** Supabase (PostgreSQL)
- **Animations:** Framer Motion
- **Build Tool:** Vite

---

## 🔧 Installation

Clone the repo and install dependencies:

```bash
git clone https://github.com/your-username/dripster.git
cd dripster
npm install

Then, build the project:

npm run build

To run the dev server:

npm run dev
